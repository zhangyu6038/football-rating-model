# 足球投注分析模型 V2.0

自动化足球竞彩分析系统，基于四层评级引擎（M/H/Q/Odds）对比赛进行量化评分，并生成投注组合策略与风险对冲建议。

## 核心流程

1. **数据采集**：通过 WebBridge 抓取竞彩官网公开赔率数据
2. **分层评级**：赛事宏观(M) / 对阵基本面(H) / 球队品质(Q) / 赔率微观(Odds) 四层评分
3. **智能校准**：RSI 市场情绪 + PRD 认知滞后补偿 + 黑天鹅对冲
4. **组合优化**：333 法则硬约束（最多3组、3倍、30元）+ 风险调整收益最大化
5. **报告输出**：Markdown 分析报告，含压力测试与决策建议

## 快速开始

```bash
pip install -r requirements.txt
python src/main.py --input data/samples/match_sample.json
```

## 项目结构

- `src/` — 核心源码（评级引擎、校准、优化、报告生成）
- `tests/` — pytest 单元测试
- `prompts/` — WebBridge 指令与 Agent 调度提示词
- `data/samples/` — 样本数据
- `reports/` — 每日输出报告
- `logs/` — 运行日志

## 合规声明

本系统仅访问中国体育彩票官方网站公开页面，输出为数学分析研究报告，不构成任何投注建议。请理性购彩，未成年人不得参与。
